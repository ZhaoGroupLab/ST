# 基于 bin100 分辨率的空间聚类与解剖注释一致性分析流程

本项目用于评估空间转录组聚类结果（bin100 分辨率）与经典解剖学细胞类型注释之间的一致性。  
通过计算 Jaccard 指数，定量反映算法聚类结果与手动注释区域在空间分布上的匹配程度。

---

## 📁 项目内容说明

本仓库包含以下分析模块：

- 聚类图像与注释图像的空间分类矩阵提取；
- 空间分类矩阵格式转换与编码；
- Jaccard 一致性指数的计算与可视化输出；
- 聚类与注释图像的空间分布可视化。

---

## 🛠️ 主要脚本说明（按执行顺序）

| 脚本名称 | 功能描述 |
|----------|----------|
| `01_cluster_image_to_matrix.py` | 读取聚类图像 `bin100.png`，生成空间分类矩阵 `bin100.xlsx` |
| `02_annotation_image_to_matrix.py` | 读取手动注释图像 `jp-bin100.png`，生成分类矩阵 `jp-bin100.xlsx` |
| `03_consistency_jaccard_analysis.py` | 比较两者矩阵并计算 Jaccard 指数，输出 `match_result.xlsx` 和热图 |
| `04_plot_cluster_bubbles.py` | 绘制 `bin100.xlsx` 聚类分类矩阵的空间扇形图 |
| `05_plot_annotation_bubbles.py` | 绘制 `match_result.xlsx` 一致性矩阵的空间扇形图 |

---

## 📊 输出结果文件

| 文件名 | 内容说明 |
|--------|----------|
| `bin100.xlsx` | 聚类图像解析得到的空间分类矩阵 |
| `jp-bin100.xlsx` | 注释图像解析得到的空间分类矩阵 |
| `match_result.xlsx` | 聚类与注释分类的空间匹配结果（二值矩阵） |
| `match_figure.pdf` | 一致性匹配结果的可视化图（扇形图） |
| `bin100.png`、`jp-bin100.png` | 原始输入图像（聚类结果图与注释图） |
| `bin100_figure.pdf` | 聚类结果空间分布图（扇形图） |

---

## 🔧 使用说明

1. 准备 bin100 聚类结果图 `bin100.png` 与注释结果图 `jp-bin100.png`；
2. 依次运行脚本 `01 → 02 → 03 → 04 → 05`；
3. 输出的矩阵和图表可用于空间一致性评价、论文补充材料展示等。
